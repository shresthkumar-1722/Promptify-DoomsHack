## 💻 How to Run in VS Code

1. **Open Folder in VS Code**:
   - Open VS Code.
   - Go to `File` > `Open Folder...`
   - Select `/Users/shresthmac5/.gemini/antigravity/scratch/it-roadmap-webapp` (or your preferred project directory).

2. **Launch Live Server**:
   - Install the **Live Server** extension by Ritwick Dey from the VS Code Marketplace.
   - Right-click `index.html` and select **"Open with Live Server"**.
   - Your browser will launch automatically at `http://127.0.0.1:5500`.

3. **Or Open Directly in Browser**:
   - Simply double-click `index.html` on your Mac. Everything runs natively with zero dependencies or build steps!

## ✨ Features & Highlights

- **Futuristic AI & Engineering Theme**: Deep dark blue `#050814` canvas, glowing neon cyan `#00f0ff` & electric blue accents, scanlines, and glassmorphism.
- **Interactive Neural Particle Grid**: Real-time canvas particle network reacting fluidly to cursor movements.
- **Interactive Linux Terminal Simulator**: Practice running real terminal commands (`help`, `roadmap`, `linux`, `salary`, `skills`, `whoami`, `clear`).
- **Persistent Progress Checklists**: Checkboxes save progress into your browser's `localStorage` and calculate your completion percentage on the fly.
- **Dedicated Multi-Page Architecture**: High-resolution image cards and deep technical breakdowns for each of the 4 years.
- **Compensation & Salary Matrix**: Realistic comparisons from Service firms (3.5 LPA) to Tier-1 Product Unicorns and FAANG/Remote US roles (45 - 90+ LPA).
- **Master Strategy Suite**: Complete 8-semester deliverables table and daily 2-hour deep-work routine.
