PHASE 02 // YEAR 2 BLUEPRINT

The Algorithmic Core: Programming Skills & DSA

Year 2 is the make-or-break crucible. This is where you transform into a relentless problem solver capable of dissecting complex algorithmic challenges under strict time pressure for Tier-1 coding assessments.

Duration: Months 13 - 24 Target: LeetCode 1800+ Knight / Guardian

1. The Weapons: Picking Your Primary Language

Do not switch programming languages every two weeks. Pick one primary language for problem-solving and master its standard library, memory management model, and syntax nuances inside out.

C++ (C++17 / C++20)

Pros: Blazing execution speed, full STL power (std::vector, std::priority_queue, std::map), the global standard for competitive programming and High-Frequency Trading (HFT).

Gold Standard for CP & HFT

Java (Java 17+)

Pros: Powerful Java Collections Framework, strong typing, clean OOP structure, extensively used in Tier-1 enterprise backends (Amazon, Flipkart, Goldman Sachs).

Enterprise & FAANG Favorite

2. The 14 Core Algorithmic Patterns (400+ Problem Roadmap)

Interviews do not test memory; they test pattern recognition. When you see an unknown problem, you should immediately identify which underlying paradigm solves it in optimal \(O(N)\) or \(O(N \log N)\) time complexity.

Pattern 1-4: Linear & Search Traversal 80 Problems

Two Pointers, Sliding Window (fixed & dynamic), Prefix Sums, and Binary Search on Answer space.

Pattern 5-8: Non-Linear Hierarchies 120 Problems

Binary Trees (DFS, BFS, Lowest Common Ancestor), Binary Search Trees, Heaps/Priority Queues, and Monotonic Stack/Deque.

Pattern 9-11: Graphs & Network Flows 100 Problems

Graph representation (Adjacency list), BFS/DFS, Cycle detection, Dijkstra Shortest Path, Kahn's Topological Sort, Disjoint Set Union (DSU / Kruskal's).

Pattern 12-14: Dynamic Programming & Recursion 100 Problems

Recursion trees, Memoization vs Tabulation, 0/1 Knapsack variations, Longest Common Subsequence (LCS), Longest Increasing Subsequence (LIS), and DP on Trees.

3. The Contest Protocol: Reaching Knight (1800+) Rating

Solving problems with unlimited time is easy. Solving 3 unseen problems in 90 minutes under a ticking timer is what separates high-package candidates from the rest.

The Weekly Contest Cadence:

  • Saturday 8:00 PM: LeetCode Biweekly Contest (participate without distractions).
  • Sunday 8:00 AM: LeetCode Weekly Contest.
  • Post-Contest Review (Mandatory): Upsolve questions Q3 and Q4 within 24 hours. Analyze top submission codes to absorb idiomatic optimization tricks.

4. Core Computer Science Fundamentals

In Tier-1 technical rounds (Google, Uber, Microsoft), round 2 or 3 frequently quizzes you on low-level OS threading, database indexing, and deadlocks.

DBMS

B+ Tree indices, ACID properties, Transaction isolation levels, Normalization (1NF to BCNF), and SQL joins.

Operating Systems

Process vs Thread, Semaphores & Mutexes, Deadlock detection/prevention, Virtual memory, and Paging.

OOP & Design

Encapsulation, Polymorphism, Abstraction, Inheritance, and the foundational SOLID principles.
